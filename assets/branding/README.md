# PhoneDex branding assets

- `hero.jpg` — 1600 × 800 README banner.
- `hero-background.jpg` — reusable generated background plate used to compose the banner and social preview.
- `social-preview.jpg` — 1280 × 640 Open Graph / GitHub social-preview artwork.
- `wordmark-on-dark.svg` and `wordmark-on-light.svg` — transparent wordmarks for dark and light surfaces.
- `icon.svg` and `icon.png` — square PhoneDex avatar/icon.
- `architecture.svg` — the README media and control-flow diagram.

The wordmark uses an original PhoneDex call-loop/audio glyph as its `o`. It does not reproduce or include the Codex or OpenAI logo.
